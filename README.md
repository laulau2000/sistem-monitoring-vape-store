# sistem-monitoring-vape-store
Satu sistem untuk memantau penjualan, kasir, dan stok seluruh cabang vape store Anda. Dashboard monitoring penjualan multi-cabang, kasir (POS) cepat dengan cetak struk, laporan laba berbasis HPP, hingga pantauan ketersediaan stok gudang — semuanya dalam satu aplikasi berbasis web yang ringan dan mudah dipakai.
